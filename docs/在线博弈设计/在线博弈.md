下面把\*\*在线博弈层（MA-VLA, 关节级协作）\*\*从设计到实现一次性讲全：目标函数、矩阵定义、求解器、门控与约束、与 G0 的三阶段训练如何对接、以及可直接照抄的伪代码与超参表。

---

# 1) 问题设定（谁在“博弈”）

* **玩家**：每个关节 $i=1\dots d$（单臂/多臂统一成一张图）。
* **输入**（每个控制周期 $t$）：

  * 来自 VLA 的关节先验 **$\mu\in\mathbb{R}^d$**（G0 的动作片段首帧）与不确定度 **$\sigma$**（见 §6）。
  * 形态图（URDF→图）：节点=关节，边=连杆/跨臂约束。
  * 上一时刻动作 $a_{t-1}$。
  * （可选）任务梯度 **$g$**：几何梯度或 **Q** 梯度。
* **输出**：本周期实际下发的关节动作 $a^+$。

---

# 2) 潜在式协作博弈（一次近端解）

我们把“协作+安全+信任先验+逐利”统一为一个**强凸势函数**，一次近端就给解（或 K=2 少步改进）：

$$
\min_{a\in\mathcal{C}}\;\;\Phi(a)
=\underbrace{\tfrac12\|a-\mu\|^2_{\Sigma^{-1}}}_{\text{信任先验}}
+\underbrace{\tfrac{\lambda_{\text{in}}}{2}\,a^\top L_{\text{intra}} a
+\tfrac{\lambda_{\text{ex}}}{2}\,a^\top L_{\text{inter}} a}_{\text{形态耦合/协作}}
+\underbrace{\tfrac{\beta}{2}\|a-a_{t-1}\|^2_{W}}_{\text{平滑/安全}}
\;\;-\;\underbrace{\eta\, g^\top a}_{\text{逐利（可选）}}
$$

* $\Sigma=\mathrm{diag}(\sigma^2)$（先验置信）；
* $L_{\text{intra}}$：臂内拉普拉斯（父子/近邻大权重）；
* $L_{\text{inter}}$：跨臂/任务一致性（共享物体、相对位姿/力的软一致）；
* $W$：关节级安全/能耗权重；
* $g$：任务提升方向（见 §5）；
* $\mathcal{C}$：约束集合（关节盒约束、单步变化、碰撞安全距离）。

> 这是一个**强凸**问题 → **唯一解**，稳定、可快速求。

把一阶条件整理成线性系统（未投影）：

$$
\underbrace{\big(\Sigma^{-1}+\lambda_{\text{in}}L_{\text{intra}}+\lambda_{\text{ex}}L_{\text{inter}}+\beta W\big)}_{A\succ0}\,a
=
\underbrace{\Sigma^{-1}\mu+\eta g+\beta W a_{t-1}}_{b}
$$

先解无约束解 $\tilde a=A^{-1}b$，再做投影 $a^+=\Pi_{\mathcal{C}}(\tilde a)$。
若投影触发了大量激活约束，可用**一次主动集修正**（把触发关节夹到边界，解剩余自由度）。

---

# 3) 约束与投影 $\mathcal{C}$

* **盒约束**：$a_{\min}\le a \le a_{\max}$（来自执行器/控制器上限）。
* **单步变化**：$\|a-a_{t-1}\|_\infty \le \Delta a_{\max}$（抑制抖动）。
* **安全距离**（软→硬）：

  * 软：把最近距/自碰撞项二次近似并并入 $L_{\text{inter}}$；
  * 硬：投影时若发生侵入，优先沿法向量回退至安全面（一次线性化足够）。

> 绝大多数场景一次**无约束解 + 简单投影**即可达实时（<1–3ms）。

---

# 4) 矩阵的工程化生成

* **$\Sigma^{-1}$**：由 VLA 输出的 $\sigma$（或 MC-dropout/多次采样估计）取对角倒数，范围建议夹到 $[1/\sigma^2_{\max},\,1/\sigma^2_{\min}]$。
* **$L_{\text{intra}}$**：

  * 邻接权重 $w_{ij}=c_1/(1+\text{距离}_{ij})$ 或按父子连杆惯量；
  * $L=D-W$，再做行列归一防尺度漂移。
* **$L_{\text{inter}}$**：

  * 共享物体/双臂对位：在两臂末端相关关节子集之间加边；
  * 避碰：把“接近对”加入边集，权重随距离反比衰减。
* **$W$**：$\mathrm{diag}(w_i)$，与关节能耗、允许 jerk/温升相关；末端/大惯量关节取更高 $w_i$。

> 以上矩阵均稀疏，拓扑不变时**可预分解**；接触/避碰边低频更新（50–100Hz）做**低秩修正**。

---

# 5) 逐利梯度 $g$（三档接入）

* **无梯度（保守/起步）**：$g=0,\,\eta=0$ → 只做结构/安全修正，最稳。
* **几何梯度**：$g_{\text{geom}} = J(\theta)^\top K_p\,(x^\star - x_{\text{ee}})$（必要时加姿态/力控项）。
* **Q 梯度**（进阶）：外挂小型**双 Q critic**（图读出 + 动作 concat），用
  $\displaystyle g=\nabla_a Q_{\min}(s,\mu)$。

  * **门控**：双 Q 分歧/ensemble 方差 $u_Q$ 大时，$\eta\to 0$。

> Flow-Matching 的 DiT 不直接给“奖励梯度”，所以 **FM 当先验 $\mu$**，需要“逐利”就加**几何/Q**。

---

# 6) 不确定性与门控（自动调 $\eta,\lambda,\beta$）

* **先验不确定度**：$u_\mu = \mathrm{clip}(\sigma/\bar\sigma)$。
* **Q 不确定度**：$u_Q=\big|Q_1-Q_2\big|$ 或 ensemble 方差。
* **合成门控**：$u=\alpha u_\mu+(1-\alpha)u_Q$，
  $\eta=\eta_0\cdot \max(0,1-u/u_{\text{thr}})$。
* **稳态调参**：若 $u$ 高或解残差大，$\lambda,\beta\uparrow$（更协作/更平滑），$\eta\downarrow$。

---

# 7) 求解器与时延预算

* **单/双臂（≤14DoF）**：拓扑固定 → 预做稀疏 Cholesky；每步仅一次前代/回代，**<1ms**。
* **20–30DoF**：用 **PCG (1–3 次)** + 块对角预条件，**1–3ms**；边集小改动用**低秩更新**。
* **K=2** 少步迭代：重算 $g$（可选）/更新 $b$，第二次解线性系统；通常仍在预算内。

---

# 8) 与 G0 三阶段的对接

* **Stage-1（Token-BC）**：仅用于**预训练表征**，线上不经 token 头。
* **Stage-2/FM 推理**：DiT 生成动作片段 $\hat A_t$，取首帧为 $\mu$；

  * 估计 $\sigma$：对 DiT 采样 3–5 次（不同噪声种子），取 per-joint 方差；或在 DiT 顶部加一只“方差头”。
* **在线博弈**在 **DiT 后**，解 $A a=b$ + 投影，输出 $a^+$。

---

# 9) 伪代码（可直接改成 PyTorch/Numpy）

```python
def game_step(mu, sigma, graph, a_prev, state, goal, critic=None,
              eta0=0.3, lam_in=0.5, lam_ex=0.3, beta=0.4,
              a_min=None, a_max=None, delta_a_max=None, time_budget_ms=3.0):

    # 1) 形态矩阵（可缓存/预分解）
    L_intra = build_L_intra(graph)        # sparse
    L_inter = build_L_inter(graph, state) # sparse, low-freq update
    W       = build_W(graph, state)       # diag

    # 2) 置信与门控
    Sigma_inv = diag_clamped(1.0 / (sigma**2), lo=1/0.3**2, hi=1/0.05**2)
    u_mu = (sigma / sigma.mean()).clamp(0, 2).mean().item()

    g = np.zeros_like(mu)
    u_q = 0.0
    if critic is not None:
        g1, g2, q1, q2 = critic.grad_and_values(state, mu)
        g = np.where(np.abs(q1-q2).mean() < critic.u_thr, (g1+g2)/2, 0.0)
        u_q = np.abs(q1-q2).mean()

    u = 0.5*u_mu + 0.5*u_q
    eta = eta0 * max(0.0, 1.0 - u/critic.u_thr if critic else 1.0)

    # 3) 线性系统 A a = b
    A = Sigma_inv + lam_in*L_intra + lam_ex*L_inter + beta*W
    b = Sigma_inv@mu + eta*g + beta*(W@a_prev)

    a_tilde = solve_spd(A, b)  # cholesky or PCG(1-3)

    # 4) 投影：盒 + 单步变化 + 碰撞（近似）
    a_proj = clip(a_tilde, a_min, a_max)
    if delta_a_max is not None:
        a_proj = clip(a_proj, a_prev-delta_a_max, a_prev+delta_a_max)
    a_proj = collision_project(a_proj, state, graph)  # fast linearized

    # 5) 可选第2步（重算 g / b）
    # if need_iter2:
    #     mu2 = a_proj
    #     (recompute g)...; b = Sigma_inv@mu2 + eta*g + beta*(W@a_prev)
    #     a_proj = projection(solve_spd(A, b))

    return a_proj
```

# 10) 推荐超参（归一化后量级）

| 项                     | 建议范围            | 说明                       |
| --------------------- | --------------- | ------------------------ |
| $\lambda_{\text{in}}$ | 0.2–1.0         | 同臂耦合强度                   |
| $\lambda_{\text{ex}}$ | 0.1–0.8         | 跨臂/一致性/避碰软项              |
| $\beta$               | 0.2–0.8         | 平滑/抑抖                    |
| $\eta_0$              | 0.1–0.5         | 逐利强度（门控前）                |
| $\sigma$ 裁剪           | 0.05–0.30       | 先验置信的上下界                 |
| $\Delta a_{\max}$     | 0.03–0.08 rad/s | 单步变化上限（20–50Hz）          |
| PCG 残差                | $1\text{e-}4$   | >阈值则降 $\eta$ 或退回 $g=0$   |
| 时间预算                  | 1–3 ms          | 14 DoF <1ms；30 DoF 1–3ms |

# 11) 关键测试（上线前务必过）

1. **无梯度稳态**：$\eta=0$ 时任何构型都稳定、越界率≈0、jerk 明显下降。
2. **几何/Q 梯度门控**：不确定性/分歧高时自动把 $\eta\to0$，系统不发散。
3. **两步改进收益**：K=2 比 K=1 成功率/误差下降明显但时延仍达标。
4. **多臂一致**：启用 $L_{\text{inter}}$ 后 EE 相对误差/碰撞率显著下降。

## 核心要点一句话

**把 DiT/FM 给的动作当“先验 $\mu$”；用 $\Sigma^{-1}$、$L$、$W$ 形成一个强凸的协作势；有梯度就逐利、没梯度就保守；一解一投影（K=1–2）在毫秒内完成。**
这就是你的在线“博弈”层，既能**跨形态/多臂稳落地**，又能在需要时**朝任务最优方向微调**。
